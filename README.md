# BongoBD Test Cases

This repository contains a detailed Excel document of manual test cases for BongoBD's digital platforms. It is intended to assist QA engineers, developers, and project managers in verifying core functionalities and maintaining product quality.

## 📄 File Included

- **BongoBD_TestCase_Writing.xlsx**  
  An Excel sheet with organized test cases covering various features of the BongoBD application. Includes:

  - Test Scenario
  - Test Case ID
  - Preconditions
  - Test Steps
  - Expected Results
  - Actual Results (for tracking)
  - Status (Pass/Fail)
  - Priority and Severity

## 🔍 Scope of Testing

The test cases cover the following areas:

- User Registration & Login
- Video Streaming
- Search Functionality
- Subscription Management
- UI/UX Elements
- Error Handling
- Compatibility Testing (Web & Mobile)

## 🚀 How to Use

1. Download the `.xlsx` file.
2. Review test scenarios relevant to your sprint or feature.
3. Execute test steps manually.
4. Record actual results and update status.
5. Report any defects in your issue tracker.

## 📌 Contribution

QA team members can contribute by:

- Adding new test scenarios
- Updating outdated or failed cases
- Reporting bugs found during execution

Please follow proper versioning and documentation practices when updating the file.
